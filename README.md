# AEL / AEFML — Operational Excellence Command Centre (v2)

Multi-SBU manufacturing performance & loss diagnostic for **Akij Resource Limited — Operational Excellence**.

**Scope:** Flour Milling · Packing · Red Lentil · Chickpeas & Yellowpeas (AEFML, Narayanganj)

## What it does
A single self-contained page that aggregates **record-level** plant data client-side over **any Start-Date → End-Date range** (plus presets: MTD / Last month / 3 months / 12 months / All data).

## KPI model (corrected, v2)
| KPI | Formula |
|---|---|
| Availability (effective) | effective run ÷ (operation − planned downtime) |
| Performance (throughput) | Σ(ideal CT × throughput) ÷ effective run — capped 100%, flagged if >100% (SMV re-validation) |
| Quality | good output ÷ output |
| **OEE** | Availability(eff) × Performance × Quality |
| Plan achievement | **throughput ÷ target** (was output ÷ target — fixed) |
| Wastage % | wastage ÷ throughput (fixed) |
| TEEP | OEE × loading (available ÷ operation time) |
| Yield | output ÷ throughput |

**Throughput basis:** crush (Flour), cleaning input (Red Lentil / Chickpeas), output (Packing).
**Effective availability** folds in *unlogged / idle* time — run logged with zero material flow (a data-integrity leak invisible to the sheet OEE).

## Files
- `index.html` — UI shell + styling
- `app.js` — aggregation engine, charts and rules (no external libraries)
- `data.js` — compact record-level dataset (dict-encoded) generated from the source Google Sheet

## Notes
- No build step, no CDN, no dependencies. Open `index.html` directly or host it.
- Packing output is in **bags**; other SBUs in **MT** — never summed together.
